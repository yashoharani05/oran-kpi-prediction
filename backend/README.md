# Backend — O-RAN KPI Prediction xApp

Python + FastAPI backend. Serves three trained ML models and a live CSV stream via REST API.

---

## Folder Structure

```
backend/
├── main.py                    ← FastAPI entry point — run this
├── requirements.txt           ← Python dependencies
├── Dockerfile                 ← Docker image recipe
├── run_training.sh            ← Training script for inside Docker
│
├── app/
│   ├── schemas.py             ← Pydantic request/response shapes
│   ├── api/
│   │   ├── predict.py         ← GET /health  POST /predict  GET /comparison
│   │   └── stream.py          ← GET /stream/next  /status  /reset
│   ├── ml/
│   │   ├── clean_dataset.py   ← Step 1: clean the raw CSV
│   │   ├── label_dataset.py   ← Step 2: feature engineering + labelling
│   │   ├── train_random_forest.py  ← Step 3: train RF classifier
│   │   ├── train_xgboost.py        ← Step 4: train XGBoost classifier
│   │   └── train_lstm.py           ← Step 5: train LSTM (time-series)
│   └── utils/
│       ├── model_loader.py    ← Loads all three models at startup
│       └── recommender.py     ← Converts prediction → recommendation text
│
├── models/                    ← Saved trained models (generated by training)
│   ├── random_forest_model.pkl
│   ├── xgboost_model.pkl
│   ├── lstm_model.keras
│   ├── lstm_scaler.pkl
│   └── comparison_report.json
│
└── data/
    ├── raw/                   ← Place the original CSV files here
    └── processed/             ← Generated by clean_dataset.py and label_dataset.py
```

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Root health ping |
| GET | `/api/health` | Server + model status |
| POST | `/api/predict?model=` | Degradation prediction (`random_forest`, `xgboost`, or `lstm`) |
| GET | `/api/comparison` | Three-model metrics comparison JSON |
| GET | `/api/stream/next` | Next CSV row + prediction |
| GET | `/api/stream/status` | Current cursor position in dataset |
| GET | `/api/stream/reset` | Rewind cursor to row 0 |

Full API docs: `http://localhost:8000/docs` (Swagger UI, auto-generated)

## Setup and Run (Windows, without Docker)

### Requirements
- Python 3.10 or higher — https://www.python.org/downloads/
- Tick **"Add Python to PATH"** during install

### Step 1 — Create virtual environment
```
py -3.12 -m venv venv
venv\Scripts\activate
```

### Step 2 — Install dependencies
```
pip install -r requirements.txt
```
> TensorFlow is large (~500 MB). First install takes 5–10 minutes.

### Step 3 — Place the datasets(all data sets)
```
data\raw\raw1.csv
```

### Step 4 — Run the ML pipeline (once)
```
python app\ml\clean_dataset.py
python app\ml\label_dataset.py
python app\ml\train_random_forest.py
python app\ml\train_xgboost.py
python app\ml\train_lstm.py
```

### Step 5 — Start the server
```
uvicorn main:app --reload
```
API available at: **http://localhost:8000**
Interactive docs: **http://localhost:8000/docs**

## Setup and Run (Docker)

From the project root (where `docker-compose.yml` is):
```
docker compose up --build
docker compose exec backend sh run_training.sh
docker compose restart backend
```

## Common Errors

| Error | Cause | Fix |
|---|---|---|
| `Model file not found` at startup | Training not run yet | Run all 5 `python app\ml\*.py` scripts |
| `uvicorn not found` | venv not active | Run `venv\Scripts\activate` |
| `422 Unprocessable Entity` | Missing/wrong field in request | Check all 18 KPI fields in the request body |
| `503 Service Unavailable` | Model not loaded | Check startup logs |
| Port 8000 in use | Another process | `uvicorn main:app --reload --port 8001` |
